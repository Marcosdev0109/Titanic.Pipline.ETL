Bilhete para o Titanic

Escolha um dos 891 passageiros reais do dataset do Titanic. Leia o anúncio que a IA escreveu para ele como se fosse a equipe de marketing da White Star Line e vire o bilhete para descobrir o destino.

Quem sobreviveu

Taxa de sobrevivência calculada pelo pipeline a partir dos 891 passageiros. "Mulheres e crianças primeiro" aparece nos números, e a classe pesou tanto quanto.

Como foi feito

Um pipeline ETL em Python prepara os dados; o site só lê os arquivos prontos, sem nenhuma chave de API exposta.

  1. ExtractLê o CSV original com 891 passageiros e 12 colunas.
  2. TransformPandas tira o título do nome, estima 177 idades faltando pela mediana do título, completa o porto e calcula família a bordo e convés.
  3. IAPara os passageiros em destaque, um modelo de linguagem escreve o anúncio a partir dos dados, sem saber o destino.
  4. LoadSalva JSON com passageiros, estatísticas e anúncios, que este site lê no navegador.
